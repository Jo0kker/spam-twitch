SPAM Card Inspector

Code source GitHub

Affiche les descriptions des cartes et des talents de SPAM au survol dans le lecteur Twitch sur ordinateur.

Extension Twitch en cours de validation. Pour le moment, seuls les comptes de test autorisés peuvent l’installer.

Installer sur le PC du streamer

Télécharger pour WindowsVersion portable (.zip)

Windows 10/11 · 64 bits · Gratuit et open source. L’exécutable n’est pas signé numériquement.

  1. Installez et ouvrez SPAM Card Inspector. En version portable, décompressez tout le ZIP puis ouvrez SpamCardInspector.exe.
  2. Préparez le jeu. Dans l’application, vérifiez le dossier détecté et cliquez sur « Préparer SPAM ». Attendez la confirmation, puis relancez SPAM.
  3. Activez l’extension sur Twitch. Installez la version de test autorisée, puis activez-la dans un emplacement Overlay.
  4. Associez votre PC. Dans la configuration Twitch, cliquez sur « Générer mon code ». Collez-le dans l’application et cliquez sur « Associer ». Aucune adresse à saisir.

Pour chaque live

Ouvrez l’application, SPAM et votre logiciel de stream. La liste « Données du jeu » doit afficher les cartes, et l’état Twitch doit indiquer Transmission active. L’association reste enregistrée.

Fermer la fenêtre arrête l’application et la transmission. Réduire la fenêtre la laisse fonctionner.

Pour les viewers

Rien à installer sur leur PC. Survolez une carte dans le live Twitch pour lire ses capacités. La fiche disparaît quand le pointeur quitte la carte. Avant publication Twitch, les viewers doivent aussi être autorisés comme testeurs.

Si aucune carte n’apparaît

  • Vérifiez le dossier du jeu dans l’application.
  • Cliquez sur « Préparer SPAM » ou « Actualiser le module SPAM », puis fermez et relancez le jeu.
  • Ouvrez la collection ou un combat. Le test des talents reste possible sans ranked avec « Aperçu du survol et test sans ranked ».
  • Si les cartes apparaissent dans l’application mais pas sur Twitch, vérifiez l’association et l’activation de l’overlay sur la chaîne.

En cas d’erreur, contactez benjamin@codible.net avec la version de l’application et le message exact. Ne transmettez aucun code d’association ni clé.

Mises à jour et désinstallation

La version installée télécharge les mises à jour et les applique à la fermeture. Le ZIP portable se met à jour manuellement. Les versions et empreintes des fichiers figurent sur GitHub Releases.

Pour retirer l’application, utilisez les paramètres Windows. Le module ajouté dans SPAM et l’association locale sont conservés. La procédure de retrait du module figure dans le README.
