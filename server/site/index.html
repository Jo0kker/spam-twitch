Télécharger et installer pour Windows

Pour le PC du streamer · Windows 10/11, 64 bits · version 0.3.0 · téléchargement d’environ 143 Mo

Installez le compagnon une fois. Sa fenêtre d’application s’ouvre à la fin de l’installation. Fermer cette fenêtre arrête le compagnon et la transmission.

1. Installer le compagnon

Téléchargez puis ouvrez SPAM-Twitch-Setup.exe. Suivez l’assistant et laissez « Ouvrir SPAM Card Inspector » coché à la fin. Un raccourci est ajouté au menu Démarrer.

2. Connecter le jeu

Le compagnon recherche SPAM. Vérifiez son dossier, cliquez sur « Installer le connecteur », puis relancez le jeu une fois.

3. Associer Twitch

Activez SPAM Card Inspector dans un emplacement Overlay de votre chaîne. Dans sa configuration Twitch, générez un code d’association, puis saisissez-le dans le compagnon.

4. Pour chaque live

Ouvrez SPAM Card Inspector depuis le menu Démarrer, lancez SPAM et votre live. Le compagnon doit indiquer « Transmission active ». L’association est conservée.

Pendant l’examen Twitch, seuls les comptes de test autorisés peuvent utiliser l’extension. Le téléchargement du compagnon est déjà disponible.

Une application, un arrêt clair

Pour arrêter le compagnon, fermez sa fenêtre ou choisissez Application → Quitter. Réduire la fenêtre la laisse fonctionner dans la barre des tâches. Un second lancement remet la fenêtre existante au premier plan.

Pour désinstaller le compagnon, utilisez les applications installées dans les paramètres Windows. Le connecteur du jeu et les données locales sont conservés ; la procédure de retrait du connecteur figure dans le fichier README du dossier d’installation.

Version portable et informations du fichier

Open source et mises à jour

Le code source est public sur GitHub, sous licence MIT. Les installateurs sont construits par GitHub Actions avec des attestations de provenance. Code signing policy.

À partir de 0.2.1, le compagnon installé recherche et télécharge les mises à jour automatiquement, puis les installe à sa fermeture, sans couper une transmission en cours. Le menu Application affiche leur état. L’association Twitch est conservée. La version portable reste manuelle.

Pour les viewers

Aucune application à installer : les fiches apparaissent au survol des cartes dans le lecteur Twitch sur ordinateur. Elles se ferment dès que le pointeur quitte la carte.

Vérifier la connexion

Le compagnon doit indiquer « Transmission active » et détecter les cartes du jeu. L’adresse de ce site est celle du serveur ; les fiches s’affichent sur Twitch.
