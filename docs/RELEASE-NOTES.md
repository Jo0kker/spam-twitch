# SPAM Card Inspector 0.6.0

- Nouveau volet de détail inspiré de la collection de SPAM : compétences actives, passifs, précision, critique et résistances.
- Réglages streamer enregistrés par chaîne : simple/complet, gauche/droite, largeur, texte, couleurs, opacité, survol/clic, informations visibles et langue FR/EN.
- Aperçu de configuration sans live, avec données fictives clairement identifiées.
- Connecteur 0.1.4 : métadonnées publiques des cartes visibles, résistances et probabilités. Actualiser le module depuis le compagnon puis relancer le jeu pour obtenir ces données. Les anciens connecteurs restent compatibles.
- En mode survol, la fiche se ferme immédiatement en quittant la carte. En mode clic, elle reste ouverte et peut être fermée avec son bouton.

Compagnon/serveur : 0.6.0. La refonte du frontend Twitch est préparée séparément en version 0.2.0 ; elle nécessite une validation Twitch. La soumission 0.1.1 n’est pas retirée par cette publication.
