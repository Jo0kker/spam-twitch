La configuration Twitch se connecte maintenant automatiquement au service SPAM. Le streamer télécharge l’application, génère son code dans Twitch et le colle dans le compagnon : aucune adresse de serveur n’est demandée des deux côtés. Le nom du PC et l’alignement du jeu sont regroupés dans des options facultatives.

Une panne de connexion affiche une action « Réessayer la connexion ». Le compagnon accepte le code copié avec espaces et minuscules, conserve les associations existantes et utilise par défaut le service public. Les installations auto-hébergées existantes restent compatibles via leur configuration conservée.

Le nouveau parcours Twitch est livré à la copie de test 0.1.2. La version 0.1.1 en cours d’examen conserve ses fichiers précédents ; aucune soumission n’est retirée par cette publication. Le compagnon 0.3.2 apporte le formulaire simplifié et conserve la lecture des talents de 0.3.1, avec sa démo sans ranked. La lecture du véritable écran ranked reste à confirmer.

Les exécutables Windows restent sans signature Authenticode. GitHub Actions construit les distributions, publie les attestations et signe le manifeste de mise à jour.
